# 背单词

一个单文件的中文背单词网页应用，适配手机屏幕，打开即用、数据全存本地。

**在线访问：https://ayyyra.github.io/beidanci/**

## 特点

- **12 套词库，1371 词**：四六级 / 托福 / 雅思 / 考研 / 中小学 / 香港中学 / 其他，按考试类型分组
- **发音**：在线词典音库（有道），默认美式可切英式；`record` / `present` 这类名动重音不同的词不会读错
- **错题本**：收答错的词，分「全部 / 重点 / 历史」三栏；连对 3 次算掌握并滑到历史；累计错 5 次或连着错 3 次进重点
- **总错题本**：把所有词库的错题汇总在一起看
- **两种题型**：选择题（看词选中文）/ 填空题（补全例句），全局可切，默认选择题
- **答完即时反馈**：标出正确选项、例句翻译，以及四条选项各自对应的英文单词
- **三套外观**：蓝白 / 暖色 / 深色（深色只用黑白灰）
- **数据安全**：localStorage + IndexedDB 副本 + 5 代快照 +（桌面）文件夹自动备份，清空浏览器数据也能自动恢复
- **移动端手势**：左边缘右滑返回，单词卡左右滑翻卡

## 关于这个仓库

仓库里只有 `index.html`（约 450KB）和 `.nojekyll`，就是完整的应用本体——HTML、CSS、JS 全部内联，**零外部依赖**，下载下来双击也能离线用（离线版比线上版多约 2.1MB 内置发音录音）。

源码是拆开维护的（`src/` + `tools/build.mjs` 打包），不在此仓库。

## 数据说明

所有学习记录只存在你自己的浏览器里（localStorage + IndexedDB），不会上传到任何服务器。换设备或清缓存前，请用设置里的「导出备份」存一份 JSON。
